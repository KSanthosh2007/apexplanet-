# 🌍 Travel Explorer

A responsive travel discovery website designed to help users explore destinations, discover travel experiences, and find inspiration for their next adventure.

## ✨ Features

- **Destination Discovery:** Explore popular travel destinations through visually appealing destination cards.
- **Travel Experiences:** Discover different types of travel experiences, including adventure, culture, and relaxation.
- **Live Weather Updates:** Search for a city and view current weather information using the Open-Meteo API.
- **Interactive Travel Quiz:** Answer a short quiz and discover a travel destination based on your preferences.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations, and responsive design
- JavaScript – Interactive features and API integration
- Open-Meteo API – Weather information
- Google Fonts – Typography

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the `Task-3` folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
4. Explore the destinations, try the travel quiz, and check the weather.
