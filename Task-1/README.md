# Task 1 – Personal Webpage

## 📌 Project Overview
A simple personal webpage featuring Roronoa Zoro from the anime One Piece.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Character introduction
- Styled webpage layout
- Basic JavaScript functionality
- Local character image

## 📁 Project Files
- `index.html` – Webpage structure
- `style.css` – Styling and layout
- `script.js` – JavaScript functionality
- `zoro.jpg` – Character image

## ▶️ How to Run
Open `index.html` in a web browser.
