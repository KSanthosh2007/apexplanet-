# Task 2 – One Piece Adventure Website

## 📌 Project Overview
An interactive One Piece-themed website built using HTML, CSS, and JavaScript as part of the ApexPlanet Web Development Internship.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- CSS Flexbox and Grid
- DOM Manipulation

## ✨ Features

### 1. Contact Form
- Name and email input fields
- Form validation using JavaScript
- Success and error messages

### 2. Responsive Design
- Navigation bar
- Responsive layouts using Flexbox and CSS Grid
- Mobile-friendly design

### 3. Crew Registration
- Register new crew members
- Display newly registered members in the New Members section

### 4. Memories Section
- Add personal adventure memories
- Save and display memories dynamically

### 5. Adventure To-Do List
- Add adventure destinations
- Display pending adventures
- Mark adventures as completed
- Delete adventures

## 📁 Project Structure
- `index.html` – Website structure
- `style.css` – Styling and responsive design
- `script.js` – Form validation and DOM functionality
- `images/` – Website images

## ▶️ How to Run
1. Download or clone this repository.
2. Open the Task-2 folder in Visual Studio Code.
3. Open `index.html` using Live Server.
